====================================
  CineCLT - ProjetinhoTv  (v2.78 FINAL)
====================================
App de TV gratuito (HTML/JS) - tela base 1280x720
que se ajusta a qualquer resolucao de Smart TV.
Escala final ajustada: 0.56 (ideal para TV TCL/Android).
AUTO-ATUALIZACAO: veja a secao "ATUALIZACOES" abaixo.

CONTEUDO:
  index.html    -> o app completo (escala 0.56) c/ auto-update
  version.json  -> numero da versao usado pelo auto-update
  capas/        -> 23 posters de filmes (catalogo)
  avatars/      -> 67 avatares de perfil + 3 originais
  previews/     -> previas do visual
  APK/          -> CineCLT-v2.78.apk p/ instalar na TV

ATUALIZACOES (app se atualiza sozinho):
  1. Hospede a pasta ProjetinhoTv num servidor/URL fixa (ex: GitHub Pages).
  2. No index.html, preencha a variavel  REMOTE_BASE  com essa URL.
  3. Recompile o APK para o WebView abrir:  loadUrl("REMOTE_BASE/index.html")
  4. A cada mudanca: suba os arquivos no host e aumente o numero em
     version.json. A TV detecta sozinha e recarrega (toast "Atualizacao").
  - Modo local/APK sem REMOTE_BASE: continua funcionando offline; o app
    apenas avisa (via version.json) quando houver versao nova p/ instalar.

COMO USAR (web):
  1. Mantenha a estrutura (index.html + capas + avatares juntos).
  2. Abra o index.html num navegador (Chrome/Edge/Firefox).
  3. Numa Smart TV, abra via navegador local/WebView.
  4. Navegacao: setas do controle + Enter/OK. Perfis salvos localmente.

COMO INSTALAR NA TV (APK):
  Copie o APK para um pen drive, conecte na TV e abra com um
  gerenciador de arquivos (ex: X File Manager) para instalar.
  Se ja havia instalado, instale por cima (mesma chave) preservando dados.
